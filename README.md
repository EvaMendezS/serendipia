# Descubre — PWA V0

Una PWA de microaprendizaje sin scroll infinito.

## Stack

- React 19
- TypeScript
- Vite
- Zustand
- vite-plugin-pwa
- CSS Modules

## Ejecutar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Incluido en esta V0

- Home de descubrimiento
- Ruleta
- Selección aleatoria
- Lectura por pasos
- Progreso finito
- Guardados
- Historial local
- Persistencia con Zustand
- Configuración PWA
- Diseño mobile-first
- Catálogo inicial local
